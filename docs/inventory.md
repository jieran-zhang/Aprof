# AProf Repository Inventory

## Runtime and contracts

| Path | Role |
| --- | --- |
| `pyproject.toml` | Dependency-free Python 3.11 runtime package and `aprofctl` entry point |
| `src/aprof_runtime/` | Strict contracts, graph routing, machine gate, episode finalization, artifact and SQLite store |
| `schemas/` | Versioned JSON schemas for Agent/runtime boundaries |

## Skill system

| Path | Role |
| --- | --- |
| `skills/aprof/ascendc-aprof-workflow/` | Stable trace-producing user entry |
| `skills/aprof/diagnosis/` | Evidence construction and human diagnosis references |
| `skills/aprof/profiling/` | Collection/parse planning and human metric references |
| `skills/aprof/optimization/` | Graph-selected candidate proposal and human optimization references |
| `plugins/aprof-performance-workflow/` | Thin wrapper agents and orchestration |
| `skillgraph/registry.json` | Canonical capability/package/install registry |

## Trainable library

| Path | Role |
| --- | --- |
| `skillgraph/source/` | Reviewed anchors, predicates, mechanisms, transformations, and expert edge priors |
| `skillgraph/versions/v0001/` | Immutable deterministic seed snapshot |
| `scripts/compile_seed_graph.py` | Source validation and reproducible snapshot compiler |

The seed excludes injection recipes and historical FastGELU traces. Predicate
contracts that lack code are explicitly marked unimplemented.

## Benchmark and execution adapters

| Path | Role |
| --- | --- |
| `skills/aprof/benchmark/ascendc-kernel-direct-invoke/` | Core runnable-project scaffold |
| `skills/aprof/remote-kernel-deploy/` | Optional remote execution adapter |
| `skills/aprof/benchmark/ascendc-aprof-inject-problems/` | Independent benchmark/data-generation system |
| `benchmarks/cannbench/` / `third_party/cann-bench/` | External benchmark worktree/submodule state |

Injection is distributed as `aprof-benchmark-tools` and is not a dependency of
the production workflow.

## Generated and task-local state

- Registry-derived marketplace/plugin/install files are generated by
  `scripts/sync_aprof_registry.py`.
- Task traces and raw artifacts live in `<op_dir>/.aprof/` and are ignored by
  Git.
- Published graph snapshots are immutable; policy revisions are separate from
  graph source.

## Legacy artifacts

Historical FastGELU summaries and flat optimization memory may be retained for
audit, but they are `legacy_unverified` and cannot train policy value.
