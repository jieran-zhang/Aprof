# GQA device design

1. An AIV kernel maps Q to `[B,Nkv,G*S,D]` and K/V to
   `[B,Nkv,Skv,D]`; K/V are not expanded to Nq heads.
2. For each `(B,Nkv)` matrix, an Ascend C Cube `MatmulImpl` computes QK^T.
3. An AIV kernel applies dtype-consistent scale rounding, the right-aligned
   causal mask, FP32 max/exp/sum softmax, then stores weights in input dtype.
4. A second Cube matmul computes PV.
5. An AIV kernel restores `[B,S,Nq,D]`.

The largest per-row UB allocation is bounded by `Skv<=2048`: raw weights,
FP32 values, polynomial work, reduction workspace, and scalars remain below
the dav-2201 UB capacity. Cube tiling is generated by `MatmulApiTiling` for
the exact `(M,N,K)` of each stage. Intermediate scores live in device GM.

Verification reports raw MERE/MARE/max-absolute error. The pass metric also
recognizes local one-ULP equivalence and the per-element forward-error bound
`eps(dtype) * sum(abs(weight * V))`; counts and maximum bound ratio are kept
in every result rather than hiding the raw diagnostics.
