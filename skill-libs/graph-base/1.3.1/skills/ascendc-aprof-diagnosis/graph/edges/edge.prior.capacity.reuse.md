# problem.onchip_capacity_pressure → action.reuse_disjoint_onchip_buffers

## 关系与对象绑定

problem.onchip_capacity_pressure —mitigated_by→ action.reuse_disjoint_onchip_buffers。

- target→target：同一task与parent实现，绑定同一target身份；同时存活的UB/L1/L0 buffer集合及其分配阶段
- stage→stage：同一task与parent实现，绑定同一stage身份；只允许对应阶段及其已注明的直接依赖窗口
- workload→workload：同一task与parent实现，绑定同一workload身份；shape/dtype/layout/feature及有效元素域一致
