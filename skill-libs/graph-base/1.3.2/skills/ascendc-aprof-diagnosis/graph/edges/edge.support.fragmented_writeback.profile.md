# symptom.profile.fragmented_writeback → problem.fragmented_writeback

## 关系与对象绑定

symptom.profile.fragmented_writeback —supports→ problem.fragmented_writeback。

- target→target：同一task与parent实现，绑定同一target身份；同一输出tensor的相邻有效区间及MTE3/Fixpipe写回点
- stage→stage：同一task与parent实现，绑定同一stage身份；只允许对应阶段及其已注明的直接依赖窗口
- workload→workload：同一task与parent实现，绑定同一workload身份；shape/dtype/layout/feature及有效元素域一致
- implementation→implementation：同一task与parent实现，绑定同一implementation身份；当前host/tiling/kernel及编译artifact一致，不把C2变换后属性充当当前观测

## 联合条件与边界

- symptom.profile.fragmented_writeback=true
- constraint.diagnosis.fragmented_writeback.profile_scope_verified=true

原conditions字段逐值保留。历史空数组没有表达无条件因果或普适适用性；新增条件必须来自绑定scope的证据。

## 依据与判别

该profile复合观察需同时满足对象、有效域、窗口、单位与模型要求，并按本边检查区分“共同固定发射成本，但本项绑定输出就绪和写回通路”。满足后仍需比较替代解释，相关性不单独确立机制。

- 把输入MTE2与输出MTE3/Fixpipe分别计数，避免把读瓶颈当写瓶颈
- 核对输出连续性、唯一写回、buffer何时可释放

## 例外与代价

- 各输出只有在不同依赖阶段就绪，等待汇总反而延长关键路径时不支持合并
- 写回已为大包且接近带宽上限时转查带宽
