## 依据与判别

该源码复合观察绑定同一调用中连续大块输入/输出及GM带宽窗口，与机制链“有效大块搬运占据关键路径 → 在足够并发与合法对齐下，实际传输速率接近目标平台可达上限 → 进一步增加发射或缓冲不能消除算法必要字节，节省时间需减少可消除流量或增加复用”相容，因此只形成待核验候选与profile预测。它不证明现象已在profile出现，也不是因果充分条件。

- 分别计算read、write及必要时读写混合的字节/秒，不混用峰值和持续基准
- 排除冷cache、启动、并发外部负载和小包setup后核对重复窗口

## 例外与代价

- 持续有效带宽远低于可达基准且每次搬运很小则转查setup
- 较高MTE比例可来自计算少或等待，缺少实际字节与分母时保持未知
