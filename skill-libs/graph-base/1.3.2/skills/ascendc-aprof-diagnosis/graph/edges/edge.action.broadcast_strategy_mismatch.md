# problem.broadcast_strategy_mismatch → action.restructure_broadcast

## 关系与对象绑定

problem.broadcast_strategy_mismatch —mitigated_by→ action.restructure_broadcast。

- target→target：同一task与parent实现，绑定同一target身份；具有广播轴零stride、连续内轴与多个输入的输出域
- stage→stage：同一task与parent实现，绑定同一stage身份；只允许对应阶段及其已注明的直接依赖窗口
- workload→workload：同一task与parent实现，绑定同一workload身份；shape/dtype/layout/feature及有效元素域一致
- implementation→implementation：同一task与parent实现，绑定同一implementation身份；当前host/tiling/kernel及编译artifact一致，不把C2变换后属性充当当前观测

## 联合条件与边界

- symptom.source.broadcast_strategy_mismatch=true
- constraint.broadcast_semantics=true
- constraint.semantic_equivalence=true
- constraint.capacity=true
- constraint.diagnosis.broadcast_strategy_mismatch.target_stage_bound=true

原conditions字段逐值保留。历史空数组没有表达无条件因果或普适适用性；新增条件必须来自绑定scope的证据。

## 依据与判别

仅当该Problem在绑定对象/阶段上仍有可核验解释力时，在目标API支持下重组广播轴、输入复用或展开阶段才是对应候选。联合条件继承A全部原硬前提，C2可比较未知条件，C3不能越过门禁。

- 分别计算输出元素数和每输入唯一字节，不用输出字节当输入下界
- 按目标rank/axis/dtype与原始维度字节对齐核对可选API

## 例外与代价

- 同轴合并后已为高效逐元素路径或输入无复用需求时，不支持本项
- UB搬入补齐不能使不合法的原始shape满足静态Broadcast约束
- UB展开结果和临时区可能增大
- 复杂索引/搬运路径及尾处理增加
