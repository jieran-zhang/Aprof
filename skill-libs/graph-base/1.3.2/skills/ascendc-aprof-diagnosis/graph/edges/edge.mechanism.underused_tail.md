# problem.underused_task_parallelism → problem.core_tail_imbalance

## 条件关系

同一任务域既可能存在空闲核，也可能已用核之间因余数/变长成本不均出现最长核，不能把任务不足和负载倾斜合并为同一事实。

## 绑定与联合条件

- constraint.diagnosis.relation.underused_tail.same_task_domain=true
- constraint.diagnosis.relation.underused_tail.per_core_cost_model_available=true

- 同一task、parent实现、workload及绑定target；只比较已明确对应的对象和依赖阶段
- 同一task、parent实现、workload及绑定stage；只比较已明确对应的对象和依赖阶段
- 同一task、parent实现、workload及绑定workload；只比较已明确对应的对象和依赖阶段
- 同一task、parent实现、workload及绑定implementation；只比较已明确对应的对象和依赖阶段

## 判别与例外

- 先考虑已有独立外轴，再评估Split-K/Split-KV与partial成本
- 读取目标核数API与kernel mode，不用来源的48/64等样例数字
- 比较max/min任务数之外也计算变长与causal工作量
- 让任务成本模型与逐核时间排序对应，而非只比较平均利用率
- 核角色不同不能直接比较
- 任务数相同不代表任务成本相同
