# 同步范围或频次超过依赖要求

## 对象、阶段与适用域

- tile或归并循环中的全局/全流水同步及真实依赖
- kernel局部计算
- 跨阶段/跨核数据交接

旧scope=all保留作检索范围，机制成立仍须核对目标架构、dtype、shape和API支持。

## 机制链

- 局部生产消费只需要有限流水或参与核完成
- 实现却等待整个流水或所有核
- 无关工作被阻塞，产生可避免等待并抑制并行

## 预测、支持检查与反证

- 将同步收窄到真实依赖后无关等待应减少；这是prediction
- 核内独立group与跨核round边界分别审查
- 保留所有可见性和退出闭合条件，核对不同原语的目标模式/流水支持
- 每轮确有跨核归并依赖时，不能删轮末同步
- 源码有SyncAll但不在热路径或只执行一次，不足以证明性能成本

## 具体替代解释

- problem.pipeline_serialization：过宽同步是串行的一种原因，不覆盖所有buffer重用问题；检查：区分必要buffer依赖与可收窄屏障
- problem.core_tail_imbalance：全核等最慢核也可能是任务不均而非屏障范围错误；检查：对齐同步前每核工作量和到达时间

## 候选动作与成本

action.narrow_sync_scope：把等待限定到真实生产消费流水或必要参与核边界。

原硬前提：symptom.source.sync_inside_tile_loop=true；symptom.profile.overlap_low=true；constraint.semantic_equivalence=true；constraint.capacity=true；constraint.dependency_lifetime=true。

- 精细事件与核间协议更复杂
- 错误收窄会破坏可见性、造成死锁或数据覆盖

## 限制与缺口

- 只在完整同步契约可替代时实施
- 归并的核内group与跨核round示例不能推广为所有SyncAll可删除
- 本轮无同任务profile、无case_support、无收益或发生频率声明；源码形态只支持待核验候选。
