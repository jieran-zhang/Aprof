# 尾块或核间工作失衡

## 对象、阶段与适用域

- 同次调用各核任务集合、有效长度及最长核
- host任务分配
- kernel各核主循环和尾段

旧scope=all保留作检索范围，机制成立仍须核对目标架构、dtype、shape和API支持。

## 机制链

- 任务数量或单位任务成本在核间不均
- 少量核承担集中尾部、变长或causal工作
- 其他核提前完成/等待，调用时长由最长核决定

## 预测、支持检查与反证

- 在不改变owner语义时均衡任务可缩短最长核；这是prediction
- 比较max/min任务数之外也计算变长与causal工作量
- 让任务成本模型与逐核时间排序对应，而非只比较平均利用率
- AIC/AIV不同角色的时长差不能当同类核负载不均
- 逐核工作量均衡但统一等待长，应改查同步或共享带宽

## 具体替代解释

- problem.underused_task_parallelism：任务不足会有空核；本项也包含任务充足但余数或成本倾斜；检查：比较总任务、可用核与每核成本
- problem.tail_slow_path：尾路径慢是单任务处理效率，本项是任务在核间分配；检查：同时记录每核尾元素数和单位尾元素时间

## 候选动作与成本

action.balance_tail_assignment：均摊余数或按任务成本重排合法分配，保持覆盖和唯一写回。

原硬前提：symptom.profile.per_core_time_imbalanced=true；symptom.source.tail_concentrated=true；constraint.semantic_equivalence=true；constraint.capacity=true。

- 可能破坏输入局部性或cache复用
- 动态领取增加调度、原子与同步成本

## 限制与缺口

- 任务数相等不代表变长任务成本相等
- 不能把样例固定核数当平台拓扑
- 本轮无同任务profile、无case_support、无收益或发生频率声明；源码形态只支持待核验候选。
