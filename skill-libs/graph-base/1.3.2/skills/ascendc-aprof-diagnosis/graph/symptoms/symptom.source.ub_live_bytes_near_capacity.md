# 对齐后同时存活的片上 buffer 接近可用容量

## 当前观察对象与槽位

- target：同时存活的UB/L1/L0 buffer集合及其分配阶段
- stage：host容量预算；kernel分配、重叠与释放
- workload：绑定shape、dtype、layout、feature与有效元素域，不跨workload借证据
- implementation：绑定当前parent源码、host/tiling/kernel、编译配置或artifact身份

## 当前实现的复合观察

- 当前对齐后同时存活的片上buffer峰值接近已注明可用容量
- 当前每个buffer的大小、对齐、深度、alias及生存区间有对应host/kernel引用
- 当前峰值公式与目标可用容量来源一致；不要求先复用buffer或成功扩大tile

- ub_capacity_bytes：按原报告单位；比值与容量分母须绑定平台

- duration：引用目标后端实际时间单位；换算统一到s后才计算B/s，cycle需同平台频率来源
