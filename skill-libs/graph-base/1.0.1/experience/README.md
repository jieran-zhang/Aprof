# Experience by workflow stage

The canonical skill entry points remain in `skills/` and
[`skillgraph/registry.json`](../skillgraph/registry.json). These stage indexes
point to conditional Wiki evidence and independently promoted local rules.

- [Diagnosis](diagnosis/README.md): measurement scope, controls and evidence limits.
- [Parallel design](optimization/parallel/README.md): algorithm, ownership,
  reduction, synchronization and workspace.
- [Execution optimization](optimization/execution/README.md): tiles, buffers,
  transfers and pipelines within the accepted parallel structure.

Start with the stage's skill. Read one relevant [Wiki entry](../wiki/index.json)
when conditions, conflicting observations or counterexamples need detail.
Draft entries are not published optimization rules. Wiki evidence never unlocks
a graph edge whose required predicate is unknown.
