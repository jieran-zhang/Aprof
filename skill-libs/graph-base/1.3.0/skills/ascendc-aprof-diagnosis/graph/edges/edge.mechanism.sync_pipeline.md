# problem.excessive_sync_scope → problem.pipeline_serialization

## 条件关系

同一tile链中过宽等待覆盖了可独立执行的下一tile工作时，过宽同步可能造成流水串行；需证明阻断的依赖边。

## 绑定与联合条件

- constraint.diagnosis.relation.sync_pipeline.unrelated_work_blocked=true
- constraint.diagnosis.relation.sync_pipeline.dependency_graph_reviewed=true

- 同一task、parent实现、workload及绑定target；只比较已明确对应的对象和依赖阶段
- 同一task、parent实现、workload及绑定stage；只比较已明确对应的对象和依赖阶段
- 同一task、parent实现、workload及绑定workload；只比较已明确对应的对象和依赖阶段
- 同一task、parent实现、workload及绑定implementation；只比较已明确对应的对象和依赖阶段

## 判别与例外

- 核内独立group与跨核round边界分别审查
- 保留所有可见性和退出闭合条件，核对不同原语的目标模式/流水支持
- 把timeline按tile而非聚合比例展开，检查首轮预置和末轮释放
- 核对双buffer是否物理独立及容量能同时容纳
- 等待只保护真实数据/跨核归并依赖时不能推出过宽
- 总体仍可重叠但局部等待，应限制结论阶段
