- stage→stage：同一task与parent实现，绑定同一stage身份；只允许对应阶段及其已注明的直接依赖窗口

## 依据与判别

该源码复合观察绑定局部计算链中有明确dtype、舍入模式和精度边界的转换，与机制链“局部链在相邻阶段反复宽窄往返转换 → 部分转换不承担必须的数值边界或消费者dtype契约 → 额外Cast指令、临时buffer与控制增加成本”相容，因此只形成待核验候选与profile预测。它不证明现象已在profile出现，也不是因果充分条件。

- 测试/分析正常数、极值、NaN/Inf、舍入与溢出契约，禁止只比较普通随机值
- 看源API支持和实际生成指令，语法Cast不必然对应相同成本

## 例外与代价

- 双向Cast通常不互为恒等，缺数值等价证明时维持needs_evidence
