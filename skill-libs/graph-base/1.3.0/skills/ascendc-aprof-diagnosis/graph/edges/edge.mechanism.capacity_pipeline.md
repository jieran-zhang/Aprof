# problem.onchip_capacity_pressure → problem.pipeline_serialization

## 条件关系

同一片上buffer集合的容量预算确实不允许建立合法双缓冲，而有多个独立tile时，容量压力可能使流水保持串行；容量接近本身不足以推导串行。

## 绑定与联合条件

- constraint.diagnosis.relation.capacity_pipeline.capacity_prevents_overlap=true
- constraint.diagnosis.relation.capacity_pipeline.multiple_independent_tiles=true

- 同一task、parent实现、workload及绑定target；只比较已明确对应的对象和依赖阶段
- 同一task、parent实现、workload及绑定stage；只比较已明确对应的对象和依赖阶段
- 同一task、parent实现、workload及绑定workload；只比较已明确对应的对象和依赖阶段
- 同一task、parent实现、workload及绑定implementation；只比较已明确对应的对象和依赖阶段

## 判别与例外

- 用max_t(sum(aligned_bytes_i*depth_i))计算峰值，不能把所有声明简单相加
- 复用审查覆盖异步消费者、跨stage事件和scratch，而非仅C++作用域
- 把timeline按tile而非聚合比例展开，检查首轮预置和末轮释放
- 核对双buffer是否物理独立及容量能同时容纳
- 同对象已能容纳双buffer时，事件安排或真依赖是更合适解释
- 只有单tile时没有稳态重叠机会
