# 重新分配尾块

## 变换与作用对象

均摊余数或按任务成本重排合法分配，保持覆盖和唯一写回。

同次调用各核任务集合、有效长度及最长核；阶段：host任务分配；kernel各核主循环和尾段。

## 实例绑定与原硬前提

实例必须给出精确template_hash、task与parent实现、目标和阶段；参数逐项给单位、来源及有效域，关联已确认C2计划。未知信息不从样例常量或聊天推断。

- target
- stage
- workload
- implementation

- symptom.profile.per_core_time_imbalanced=true
- symptom.source.tail_concentrated=true
- constraint.semantic_equivalence=true
- constraint.capacity=true

原invariants：算子语义与精度要求保持；有效写回无重叠且覆盖完整；资源与依赖约束经核验。

## 预期效果与代价

均摊余数或按任务成本重排合法分配，保持覆盖和唯一写回；预期变化仅为prediction：在不改变owner语义时均衡任务可缩短最长核；这是prediction

- 可能破坏输入局部性或cache复用
- 动态领取增加调度、原子与同步成本

## 未知与返回规划

任一硬前提缺失、unknown或proxy则needs_evidence；明确不满足则blocked。C2可比较条件方案，C3须完成全部原前提及invariants核验。

- 目标/阶段、owner或有效元素域变化
- 算法、归并/同步拓扑、workspace owner、融合、通路或dispatch域超出已确认C2计划自由度
- 工作量、dtype、平台、容量或profile反证使原干预假设失效

## 平台与workload限制

- 任务数相等不代表变长任务成本相等
- 不能把样例固定核数当平台拓扑
