# 本地症状启发式阈值

`compress_msprof.py` 提供可执行默认值，覆盖参数必须写入草稿。这些是专家启发式，不是已校准概率或性能验收门槛。

| 变量 | 默认值 |
| --- | --- |
| Scalar 活跃比例 | 0.30 |
| MTE2 活跃比例 | 0.50 |
| 搬运启动开销假设的带宽利用率上限 | 0.60 |
| 每条 MTE 指令有效字节下限 | 16384 |
| UB 冲突比例 | 0.05 |
| 核间不均衡 | 0.10 |
| 实测/理论流量放大 | 1.20 |
| 完整机制采集次数下限 / CV 上限 | 5 / 0.05 |

判断搬运启动开销需要 MTE、带宽和粒度三个输入，缺项保持未知。Scalar 占比、冲突和不均衡可能对应多个机制；小 workload 的利用率低不一定是瓶颈。架构分母取自真实平台。

机制采集次数与性能计时分开。性能反馈和收尾遵循 [统一计时协议](unified-timing.md)，不再要求旧 30 对样本。
