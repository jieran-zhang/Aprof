# 选择敏感性示例与正式交接边界

以下是开发纸面例，数字用于解释选择，不是 NPU 测量，也不是行为评测标准答案。对应的通用规则只维护在 [Action 选择](../action-selection.md)，无需用户额外填写本页或运行工具。

## 内容相关保护：判断粒度改变方案

一个每行有 I 个输入、S 个输出的局部加权求和，正常路径每输出 K 项；候选改变累加树，并增加“扫描发现任一输入绝对值超阈值，整行执行每输出 K 项软件算术”。必须先说明这是整行触发。低值域完全在阈值内时，可以比较正常树减少的依赖链与扫描、最终 Cast 修正成本；值域跨阈值时，不能根据形状不变推定相同快路覆盖。

若已提供的固定数据表明每行都命中，原“绝大多数输出用向量树”预测已被反证。重新比较保留原顺序、保持旧路径或改变变换范围。可以仍选择原 Action 的另一实现，但不能只把反证改写成“频率 unknown”。若只有范围跨阈值而没有实际数据或分布，只知道可能整行回退，不知道精确比例；保留条件或上下界，不必强制采样输入。

修复最终 Half Cast 的相邻量化边界时，正确性依据不能仅是 FP32 误差小于 floor。新增判别、压缩和软件修正需进入完整方案；修好精度后重比可能仍选择试验，也可能放弃新树，二者都可以有依据。不能默认对所有任务开展全浮点形式化证明。

## 准备与消费：少一次调用不等于少一份数据

父方案每次生成 B 字节布局，每输出消费两次批量描述；新方案额外写 B 字节，把两次 API 合成一次，读取元素总量不变。两者都合法时，选择需要解释发射/片段减少与准备增加的竞争，不能只列两条优缺点。

当已有适用阶段观察是准备约 60 us、目标消费约 40 us，目标阶段最多只能提供其总耗时量级的节省，而且保留的读取/计算不能免费消失；若没有依据表明额外准备很便宜，保持原布局或无复制的批量描述是强替代。这里不意味着额外 B 写入一定要 60 us，也不能由此直接宣判新方案必慢。相同调用减少若在大量消费者间摊销，或有可信发射成本证据，新方案仍可能值得试验。选择需指出哪种情况成立，缺少时间就用符号竞争和下一步预测，不编造加速比。

完整 callback 含初始化、pack、geometry、sample、compact。各阶段中位数只能帮助定位变化，不能相加冒充整调用中位数，更不能将联合结果拆成各配方收益。

## 同轮多 Action 与正式链

派生函数 D=f(X) 与通道 c 无关，但 X 版本、坐标属性和数值契约固定；方案先按点计算 D，再供各通道消费。以 `reuse_derived_results` 表达保存派生结果的独立意图。C2 选择每核重算/片上保存/GM 生产消费，并统一 owner、有效域、完成依赖及 workspace；C3 在确认计划下选择保存、布局和搬运方法。

若通路还需要独立的访问重排，可另建既有 Action 的实例；若只是保存配方中的必要 CopyIn、尾部和同步，则属于同一意图的实现步骤。实际路由逐实例进行，不将命中文档取并集。只读缓存提示不会保证驻留，也不会减少逻辑字节；输出策略必须考虑后继读者和目标 SDK，不能用输入实例的证据代替输出实例。

正式 C1 的 `decision_ref`、`scheme_id/hash` 绑定共同 P 计划及各成员 O 实际选择。文字完整方案而 `schemes=[]` 只能表示尚未完成正式选择。研究授权、性能 accepted 或局部 ready 都不能补足这个身份。P_KEEP 需完整有效父计划；缺资料不表示 KEEP；P 改变且 O_KEEP 仍须实现新计划。

## 简洁后继摘要怎样影响下一次选择

当前状态列原始基线、工程保留实现和探索父本；已尝试路线只保留预测变化，例如“扫描使原快路覆盖假设失效，软件路径合法但工作增加”；剩余机会说明“重开需要低成本保护或保留原数学次序的替代”，引用原 decision/patch/结果。

更换父本不删除先前反证；同 Action 可以继续，但应说明新参数、不同对象或未回答的预测。无效计时不能宣判性能回退，源码已确认的新增复制也不会因计时无效而消失。摘要只导航，不创造执行额度或自动晋升知识。
