# 原始路径与自主比较

Host预计算multiplier/shift，按ceil(N/4096)和可用核上限分连续块；每tile一次读一次写，float执行Muls/Adds/Exp，16位先Cast FP32再三步计算及Cast回原dtype。无归约、广播、跨核同步或重复输入。

每输出2s字节GM；每tile 2次DMA、3次Vector算术；16位另2次Cast。静态UB float=8T，16位=12T，另API预留未知。

首选：在原分核/原精度下比较两物理输入/输出槽，保持T=4096为首候选；若容量不允许则先返回C2比较T而非强行减半。单份FP32临时区仍按Vector顺序复用，输入/输出槽分别以最后读完成为回卷边。

理由：连续大域已有三步Vector链，无重复GM流量可删；流水可覆盖每个多tile核的读/计算/写串行间隙，并以比将T加倍更小的额外UB换取重叠可能。更大tile虽然少接口，但固定4096已非逐元素小包且不减少Exp必要算术。

残余：Exp及Cast算术、每输出2s有效GM字节、尾部和host启动保留；base=1不能仅凭样例值域把0*x改成常量，因为原API仍允许NaN/Inf。

语义保持方案只变分块/存储/排程，必须保留每元素运算和舍入顺序；未实现，不是正确性通过。
