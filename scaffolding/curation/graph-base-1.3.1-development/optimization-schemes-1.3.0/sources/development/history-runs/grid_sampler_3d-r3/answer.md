# 已尝试路线

**1．三线性算术向量化：最终保留为 `conditional_plan`。**

拟保持坐标生成、先判界再读取、逐邻点乘法及累加顺序，将跨输出的三线性算术批量化；nearest六例保持原样，完整正确性范围仍为20例。选择理由是算术具有规则批处理结构，且可保留现有输出所有权；并非已证明它是主瓶颈。

保守拟定布局为18个FP32数组，FP16另含输出half区；原 `fpBuf` 已计入，不重复收费。其余scratch、对齐及预留记为R：

- FP16：`74T+R`字节；FP32：`72T+R`字节。
- 保留 **T=1024、单槽**起点：分别占74/72KiB，余54/56KiB。
- FP16的1536仅余17KiB；2048及1024全套双槽超预算，不采用。容量余量不等于scratch已经闭合。

令各核有效长度为Lb，批次数为 `Σceil(Lb/T)`。按表达式模型，每批约24次Mul、8次Add、一次初始化和一次写回，FP16另一次Cast，即34/35次API调用，不含同步、不等于机器指令数。
