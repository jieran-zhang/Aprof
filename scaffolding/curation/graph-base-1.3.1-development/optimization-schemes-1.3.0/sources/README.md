# 开发验收原始材料

`development/`保存本次源文件、workload、冻结事实、匿名评分、原始回答、运行元数据与检查记录；来源许可与revision随evaluation保存。只有算子R0与给定资料，无硬件结果或训练产物。原始记录中的路径保留生成时身份，包内对应路径由`MANIFEST.json`定位；其中绝对路径仅是溯源元数据，不是运行依赖。

每个`prompt.txt.gz`解压后是送入无工具主体的原始文本，其sha256可与同目录RUN.json核对。没有保存认证头、密钥、完整流式事件或模型内部推理。评分在解盲前锁定；grades.json原字节保持，不能修改评分来适应最终报告。素材和subject回答不属于日常workflow必读内容。
